# 網站說明（小助手的知識庫）

這個檔案就是小助手對「網站怎麼用」的全部認識。
改這裡就等於改它的回答，不用動程式碼，存檔後重新部署即可生效。

今天的新聞內容不在這裡——那是 `server.py` 每次即時去抓
`{slug}.json` 的，會自動保持最新，不用你維護。

這份說明目前是完整的，沒有待填項目。之後網站有變動時（例如開放訂閱、
新增主題、改變更新時間），記得回來同步修改這裡，否則小助手會照舊答案回答。

## 這個網站是什麼

- 名稱：每日新聞簡報
- 網址：https://lng255639-cpu.github.io/news-agent/
- 把過去 24 小時的新聞整理成幾則重點。同一件事被很多家媒體報導時，
  會合併成一則，並標示有幾家報導過。
- 每天台北時間早上 7 點自動更新一次，由 GitHub Actions 在雲端執行，
  站長的電腦不用開機。排程不保證準時，實際上常會延遲 5 到 30 分鐘。
- 內容分成四個主題，從首頁點進去就是那個主題的當日重點：
  **AI**、**半導體**、**台灣科技**、**國際**。

## 一則新聞卡片有哪些部分

1. **佐證強度**——卡片最上方那排小格子，代表有幾家媒體獨立報導這件事。
2. **標題**——點下去會直接開啟原始報導。標題經過改寫，
   讓它在不看內文的情況下也講得清楚。
3. **摘要**——發生了什麼事，兩三句話。
4. **為什麼重要**——這件事的意義或影響。
   這是這個網站跟一般新聞列表最不一樣的地方。
5. **時間與來源**——最早的報導是什麼時候發出的，以及有哪些媒體報導過。

## 那排小格子（佐證強度）怎麼讀

這是整個網站最值得注意的一個記號。它代表**有幾家不同的媒體報導了
同一件事**，不是這則新聞被點了幾次，也不是它有多熱門。

| 格子數 | 意思 |
|---|---|
| 1 格 | 只有一家報導。可能是獨家搶先，也可能還沒被查證。 |
| 3 格 | 幾家都報了。多半是確實發生的事。 |
| 5 格（滿格） | 五家以上報導。當天的大事。 |

提醒：格子少不代表假的，格子多也不代表一定重要——有些話題本來就
只有特定媒體在追。它是一個判斷的參考，不是結論。

## 時間標籤怎麼看

- 每則會標「3 小時前（今天 11:00）」這樣的時間。
- 這指的是**最早那則報導**發出的時間，也就是事情大致發生的時間點，
  **不是**最新一則跟進報導的時間。
- 有時候後面會多一句「持續報導至 1 小時前」，
  代表這件事還在發酵，到剛才都還有媒體在跟進。

## 新聞的順序是怎麼排的

- 大致依重要性排序。
- 報導家數是主要參考，但不是唯一依據。
- 只有一家報導的重大宣稱會被保守看待。
- 業配、股價漲跌、內容農場會被排除。

## 內容是怎麼產生的

網站背後是一支叫 news_agent 的程式，流程分四段：
**問題理解 → 廣泛撈取 → 事件聚合 → 排序摘要**。

- 新聞來源是 Google News 的繁體中文 RSS，涵蓋各家媒體。
- 「有幾家媒體報導同一件事」是程式比對算出來的，不經過 AI。
  這個指標免費、穩定，比標題聳動程度可靠得多。
- 標題改寫、摘要、以及「為什麼重要」這三項由 AI 生成。
- 判斷兩則報導是不是在講同一件事，用的是字元層面的相似度比對。

## 連結會帶你去哪

- 點標題會開啟原始新聞頁面。
- 這個網站只放標題、摘要和連結，**不轉載內文**。
  新聞內文有著作權，完整報導請到原媒體閱讀，流量也應該回到原網站。
- 如果同一件事有多家報導，連結會指向其中最新的那一則。
- 部分連結會先經過 Google News 的轉址頁再跳到原網站，這是正常的。

## 已知的限制

這些是站長知道但目前還沒解決的問題，被問到可以坦白說明：

- **有些連結會停在 Google News 的轉址頁**。那串 `CBMi...` 開頭的網址是
  加密的，真實網址要靠瀏覽器端的 JavaScript 算出來，程式抓不到。
- **中文和英文報導同一件事時不會合併**。相似度比對是看字元，
  「激增 40%」和「大增四成」在字元層面幾乎沒有交集，所以會被當成兩件事。
- **某個主題偶爾會顯示「本次未能產生」**。單一主題失敗不會拖垮整個網站，
  那個主題會標示出來，隔天更新就會恢復。
- **沒有歷史存檔**。每天的內容會覆蓋前一天的，看不到過去幾天的簡報。
- **沒有搜尋功能**。

## 常見問題

### 這個網站是誰做的？為什麼做？

由一位不具名的開發者維護，這是一個純學習性質的個人專案，不是商業服務，
背後也沒有公司或團隊。做的動機是練習，順便解決自己每天早上翻各家
新聞太花時間的問題。

因為是個人專案，沒有服務保證，也不承諾一定會一直維護下去。

### 發現錯誤或想回報問題，要怎麼聯絡？

到 GitHub 開 issue：
https://github.com/lng255639-cpu/news-agent/issues

摘要寫錯、連結壞掉、兩件不同的事被合併成一則、明明是大事卻沒出現，
這些都歡迎回報。附上是哪個主題、哪一則會比較好處理。

### 有沒有電子報訂閱、RSS 或手機 app？

目前都沒有。要看內容就是直接開網站。

### 有沒有收費？以後會收費嗎？

不會，完全免費，也沒有收費的打算。網站上沒有廣告，
所有連結都指向原始新聞媒體。

### 為什麼是這四個主題？以後會增加嗎？

目前就是 AI、半導體、台灣科技、國際這四個，暫時不會更動。

### 新聞是根據什麼標準被排除的？

業配、單純的股價漲跌、內容農場這幾類會被排除，判斷是由 AI 在
排序摘要那一段自動做的，不是靠一份固定的黑名單或關鍵字規則。

這代表判斷不會百分之百一致——偶爾會有漏網之魚，也可能誤刪掉
其實有價值的內容。覺得某則不該出現、或某則不該被漏掉，
歡迎到 GitHub 回報。
